# Ruang Kirim HP (Android)

Pasangan versi PC. Proyek Android Studio (Java). Dirakit jadi APK lewat Pabrik SuS.

- Protokol: `PROTOKOL.md`, sama dengan versi PC.
- `Proto.java` / `Core.java`: mesin kirim/terima (Java murni, sama perilakunya dengan `lib/core.js` versi PC).
- `KirimService.java`: layanan latar (pencarian WiFi, penerima, pemberitahuan).
- `MainActivity.java`: tampilan (WebView) + pemilih file, Bagikan, pindai QR.
- `assets/ui/`: tampilan, salinan dari `app/` versi PC.
